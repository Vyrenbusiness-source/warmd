# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be kind and patient. Assume good intent.
- Critique code and claims, never people.
- No harassment, insults, sexualized language or imagery, and no publishing of others' private information.
- Back a claim about speed or tokens with a run others can repeat.

## Scope

It applies in issues, pull requests, discussions and every other project space, and when you represent the project elsewhere.

## Enforcement

Report unacceptable behavior privately to the maintainer through the contact on the [owner's GitHub profile](https://github.com/Vyrenbusiness-source). Every report is reviewed and kept confidential. The maintainer may edit or remove contributions and ban, temporarily or for good, anyone who breaks these rules, following the enforcement guidelines of the Contributor Covenant.
